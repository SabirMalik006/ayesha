projects

Things I've built while learning

Library Management System

Personal Project

A desktop application that lets a librarian add, search, issue and return books without juggling paper registers. To test it with realistic data instead of dummy entries, I pulled in a small book-catalog dataset from Kaggle to pre-populate the library's records.

Python Kaggle Dataset CRUD Operations

7-Segment Display Decoder

Academic — DLD

A Digital Logic Design coursework project where I designed and simulated a decoder circuit that converts a binary/BCD input into the correct pattern of lit segments on a 7-segment display — built entirely from logic gates.

Logic Gates Circuit Design Simulation

Quiz Management System

Academic — Assembly

A console-based quiz application written in Assembly language. It displays questions, reads the user's answer, checks it against the correct option, and keeps score — all handled at the register and instruction level.

Assembly Language Low-level Logic Console I/O
